## Findings (actionable)

- **F1 · medium · goal 6** — Journal has no read path: CLI/MCP expose only `journal.add`; the extension brief re-injects corrections but not decisions. "Re-read before resuming" is unfulfilled. Fix: `guard_journal`/`journal list` verb + ≤3 recent decisions in the brief.
- **F2 · medium · goal 4** — Orientation unreachable outside the extension: no MCP/CLI verb, so non-pi hosts get no orientation. Fix: `guard_orientation` tool + `orientation` CLI verb.
- **F3 · medium · goals 3/8** — Diff audit ignores untracked files: 600-line untracked file read as Δ0 (live-confirmed). `git diff HEAD` cannot see them. Fix: bounded untracked counting (intent preserved in `/tmp/aborted-run-diffscope.patch`).
- **F4 · low-med · goal 9** — Loop streaks parse only pi's exact `Command exited with code N`; failed bash without that phrase → `ok=null` → never counts. Conservative (no false blocks) but can starve goal 9. Fix: widen parser or count `isError`+exit-null as failure unless abort-pattern.
- **F5 · low · goals 3/8/10** — `diff` on a repo with no commits prints raw git stderr ("fatal: ambiguous argument 'HEAD'…"). Fix: friendly "no baseline yet" verdict + suggest initial commit.
- **F6 · info** — Session-scoped stats use `PC_SESSION_ID`/`"default"` for MCP+CLI; concurrent sessions on one project share the label (extension uses real session ids).
- **F7 · info** — Mid-session install is invisible until restart (`/reload`); expected, documented in README.
- **F8 · info (verified OK)** — >12 constraints stored but not re-injected; warning surfaces correctly. Documented token-discipline trade-off.
